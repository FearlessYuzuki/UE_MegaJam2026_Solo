# 第一幕教学路线与字幕

关卡：`/Game/MegaJam2026/Maps/Gameplay/L_Tutorial`。依据 `Content/Resources/Assets/Resources/Outro.txt` 第一幕设计。

地图中的课程位于 `Tutorial/ActOne` 文件夹；主菜单公园、样板区、雨声、雾和其他背景资产保留。九块主体地形不相交，水面作为走失或跳跃失误后的安全缓冲区。

## 路线

1. 玩家从中心出生点下落，落地后先显示完整的 WASD / Ctrl / 空格 / 长按空格操作提示，再播放欢迎、环顾和前进的原台词。
2. 落地 10 秒后，三个入门平台和红色升降板一起升起。前两个平台相差 120cm；第三个平台相差 200cm，配合长按空格体验攀爬。
3. 第三个平台上的低门净空 140cm，站立角色高 320cm、下蹲高 80cm，按 Ctrl 通过。门后是红色升降板。
4. 红板升起后续三块地形；两个 120cm 台阶引导玩家到绿色弹射板。高塔比弹射平台高 1000cm，不能靠普通跳跃到达。弹射初速度 1700cm/s，高塔留出宽落点。
5. 最高处紫色板把重力强制转为 +Z。玩家自然落向上方世界的宽接应平台，在倒置世界继续两次短跳。首次翻转时预设接应平台为安全点；此后每次在倒置平台站稳都会更新安全点。沿重力方向掉出安全平台 250cm 后自动返回其中心，并用 0.3 秒黑屏渐显缓冲，保留倒置重力、地块、压力板和字幕进度。返回点参与存档，Continue 后仍有效。
6. 读完“去吧，走向最后一个踏板，前面才是演出的开始。”后，黄色完成板出现。踩下后直接播放第二幕转场并打开 Main。

## 字幕分配

| 段落 | 触发时机 | 台本内容 |
| --- | --- | --- |
| `Tutorial.Intro` | NewGame 首次落地 | 操作提示；欢迎来到教学关卡；看看周围；往前走 |
| `Tutorial.GroundRaised` | 首批平台升起完成 | 往前走，踏上这片土地 |
| `Tutorial.Trace` | 首次踩上第一块草地 | 所经之地，是你经过的痕迹 |
| `Tutorial.PlateIntro` | 首次到达低门平台 | 世界并非只有黑白；介绍不同压力板 |
| `Tutorial.Lift` | 踩红板 | 人生中的跳板与未知地块 |
| `Tutorial.Launch` | 首次被绿板弹射 | 不同踏板的功能与脱离泥潭 |
| `Tutorial.Flip` | 紫板翻转重力 | 很惊讶吧；宇宙中的另一个你 |
| `Tutorial.Exit` | 翻转后在上方世界落地 | 走向最后一个踏板，演出即将开始 |
| `Main.Landing` | 第二幕 Main 首次落地 | 原台本的主关卡落地段落 |

字幕沿用 Noto Sans、半透明黑底白字，按 Settings 的游戏内语言选择中英文。连续触发时进入队列，避免后一段截断前一段。字幕当前句、剩余时间和待播段落参与保存；Continue 接着读，不重播开场。

## 章节转场

复用 NewGame 的跨地图遮罩：0.55 秒淡出、全黑加载、3 秒章节标题、1.5 秒渐显。第一幕为 `第一幕：“教学”` / `Act I: "Tutorial"`；第二幕为 `第二幕：“∞”` / `Act II: "∞"`，均为居中白字。

教学完成板关闭全世界恢复色彩和通关调试提示，正式 Main 的最终目标保留原有世界恢复色彩行为。Main 的地编及 BGM 资产不改动。

控制器为 `BP_TutorialOpeningSequence`，场景实例名 `Act1_Director`。地形、压力板和旁白资产均通过详情面板中的显式引用连接。
