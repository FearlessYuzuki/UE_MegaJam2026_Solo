# 第二幕圆环关卡

地图为 `/Game/MegaJam2026/Maps/Gameplay/L_Main`。根据用户于 2026-11-15 的新要求，主线使用圆环，保留 Outro.txt 原文中关于莫比乌斯环的叙述。中文和英文字幕继续使用现有 DT_LoopNarration 与语言设置。

## 空间与玩法

- 圆环半径 270m，直径 540m，中心 `(1600, 21156)` cm，路线约 1663.5m。
- 224 块实体：用户原型 10 块、连接区 5 块、四段圆弧各 52 块、终幕平台 1 块。外围 40 个巨观、样板区、环境、雨声、四首 BGM 保留。
- 四段圆弧分别位于下方、上方、下方、上方世界。每段走到紫板后翻转到下一段同 XY 的宽接应台；第四次回到下方终幕台。圆环沿圆周推进，不构造莫比乌斯扭转面。
- 每段平台离水高度从 9m 至 81m，末端 71.4m；普通上跳 160–180cm，攀爬台阶 320cm，下降步差 260–350cm。
- 16 处主线弹射，绿色板初速 1800cm/s，高台比起跳台高 12m；目标加宽，支持助跑带入水平速度。
- 32 处攀爬台阶、16 处内外错位窄落点、8 处 140cm 净空下蹲通道。跳跃、空中修正、长按空格攀爬和 Ctrl 下蹲沿用项目现有角色能力。
- 最后一次翻转后，在终幕绿色板以 6500cm/s 弹到空中，播放 Main.End。旁白读完显现黄色终点，踩下恢复全场色彩并沿用原饱和度脉冲。
- 时间取决于身法、探索与失败次数；路线长度用于延长体验，不承诺未经手工试玩测定的通关分钟数。

## 用户原型与升降

`BP_PressurePlateLift_C_3` 是起始红板，专用 `Lift Region Tag=Main_Lift_01`，控制用户选中的 9 块 BP_BasicGroundBlock。已开启 Requires Lift 与 Start At Lift Target，编辑器位置为升起后位置，运行时从其下方 600cm 开始。

第二块红板 `BP_PressurePlateLift_C_4` 随其下方高柱升起，分组 `Main_Ring_Opening`，用于连接区与圆环前三块。

原型仅修正薄地块 `BP_BasicGroundBlock_C_7` 的相互穿插：移至 `(1330,-5420,-19988)`，平面缩为 `300×300cm`。两块红板底座对齐支撑面，避免嵌入地形。出生点移至起始地块上方 `(45,-5844,-17000)`。

## 字幕与恢复

`AMainRingSequence` / `Act2_Director` 负责四次翻转顺序、接应地块升起、字幕排队、终幕与跌落恢复。

| 时机 | 字幕段 |
| --- | --- |
| Main 首次落地 | Main.Landing |
| 第一次翻转 | Main.Flip1 |
| 第二次翻转 | Main.Flip2 |
| 第三次翻转 | Main.Flip3 |
| 第四次翻转后的终幕弹射 | Main.End |

字幕排队避免截断。Continue 保存翻转次数、当前检查点、终幕与结束状态、旁白当前行和队列，以及已有地块与玩家状态。

当前重力方向下，每次实际站到课程地块就更新安全落点；脚部坠至该面以下 450cm 后返回其中心，保留重力和旁白进度。翻转刚发生就指定下个接应台，首次错过也能恢复。350cm 正常下落台阶不会被拦截。
