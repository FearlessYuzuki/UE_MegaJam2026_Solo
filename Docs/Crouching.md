# 下蹲镜头与蹲行速度

## 默认行为

- 地面蹲下和成功起身时，第一人称镜头各用 0.2 秒平滑过渡。
- 胶囊仍由 UE 原生下蹲逻辑即时调整，只有镜头高度变化做平滑，不改变碰撞判定。
- 使用胶囊实际世界位移进行镜头补偿，兼容当前正向/反向重力；空中胶囊中心未移动时，不额外制造镜头高度变化。
- 过渡中反向操作，从当前镜头位置衔接新的过渡，不回跳到旧起点。
- 头顶受阻、未成功起身时，不启动镜头抬升。
- 地面蹲行最高速度为 300 cm/s；进入地面蹲行后也限制已有过高速度，不仅限制输入加速。
- 站立移动及空中 Source 加速逻辑保持原样；攀爬期间仍禁止下蹲。
- 重生和重力镜头翻转时清除下蹲镜头残余补偿。

## 调参

| 位置 | 参数 | 默认值 |
| --- | --- | --- |
| `BP_PlayerCharacter` 类默认值 → `Camera / Crouch` | `CrouchCameraTransitionDuration` | 0.2 秒 |
| `CharacterMovement` 组件 → `Move Settings` | `MaxCrouchSpeed` | 300 cm/s |

本项目使用自定义 Source 移动，地面蹲行速度以 `MaxCrouchSpeed` 为准，不再由未接入该移动逻辑的 `MaxWalkSpeedCrouched` 决定。

## 验收步骤

1. 保存关卡、重启编辑器加载最新模块，在 PIE 中检查蹲下和起身各约 0.2 秒。
2. 快速交替按下、松开下蹲键，检查镜头不瞬间回跳。
3. 蹲在低顶下松开按键，检查角色和镜头保持蹲姿；移出低顶后成功起身再平滑抬升。
4. 开启速度显示，检查地面蹲行直走、斜走均不超过 300 cm/s，松开后恢复原站立速度。
5. 正向/反向重力各检查一次，过渡中重生或触发重力翻转后无残留偏移。

已通过 UE 5.8 Editor Development 的 UHT、C++ 编译及带后缀模块链接；以上 PIE 运行验收尚未执行。
