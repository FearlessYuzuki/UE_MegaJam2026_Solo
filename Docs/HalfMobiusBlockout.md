# Main 半环灰盒与压力板测试区

## 一、范围与设计

- 主场景：`/Game/MegaJam2026/Maps/Gameplay/L_Main`。
- 本轮是 Refunct 式分段方柱、跳跃间隙和高差的双世界半环灰盒，不是连续扭转曲面的数学莫比乌斯带。
- 暂定动线：下层起点 → 半环岛链 → 末端重力板 → 上层落点 → 反向沿上层半环返回 → 阶段目标板。
- 另一侧半环保持空白，供后续扩展；目前也没有实现墙面行走、连续 90° 扭转或完整闭环流程。
- 升地块支线和弹射板先作为可选机制验证，不把它们当作已经平衡好的必经挑战。

## 二、Main 与教学关同步的环境

从 `L_Tutorial` 复制了 60 个环境 Actor，不修改教学关或第三方源资产：

- 上下水面与底板：平面范围 2 × 2 km，水面 Z 为 -20000 / +20000 cm，间距 400 m。
- 两侧光照、SkyLight、天空、高度雾、曝光后处理。
- 高度雾密度 0.495、终止距离 25000 cm、曝光补偿 -1 EV；颜色参数沿用教学关。
- 保留 `LimitedFogView` 世界标签，使用现有游戏视图 250 m 裁剪。
- 四张 `TransitFog` 雾卡保留标签和实例配置，游戏主视图隐藏规则沿用现有 C++。
- 两侧局部雨效、40 个边界外远景巨构、四面空气墙。

雨效与 EasyFog 的既有性能风险没有在本轮修复；环境同步不意味着这些系统已通过最终性能验收。

## 五、生成、备份与验证

生成脚本：`Scripts/Editor/BuildHalfMobiusBlockout.py`，在 Windows Unreal 的 Python 控制台执行，先显式设置 `BLOCKOUT_TARGET="main"` 或 `"pressure_test"`。
脚本只为指定当前地图添加内容，不负责自动切图或同步环境；遇到已有对应生成标签会拒绝重复运行，不会自动删除、覆盖现有灰盒。
修改前的 Main 和 MovementTest 备份位于 `Saved/Backups/HalfMobius_20261115_032715/`。

结构核对覆盖 60 个环境副本的类、变换，光照/雾/曝光关键参数、2 km 平面边界、172 块岛屿碰撞、上层朝向和唯一 PlayerStart。
手动场景截图属于编辑器视口验证，不等同于玩家视角效果或性能数据。

PIE 压力板验证使用玩家 Pawn 瞬移穿入真实重叠区域，不直接调用压力板的效果函数：

- 升地块板启动同组 3 块；每块实际位移 600 cm，到位恢复碰撞并关闭 Tick。
- 目标板锁存，测试关仍运行。
- 弹射板两次触发的即时上向速度均为 1200 cm/s，可回弹再用。
- 下层重力板切换到 +Z，上层倒置返回板切换回 -Z。

Main 另做了出生与跨世界落点的局部 PIE 检查：不传出生位置覆盖，从 Main 的 PlayerStart 生成；瞬移至末端重力板触发后保持自然飞行，在 16 秒检查点已落到上层对应平台，移动模式为 Walking，重力为 +Z。没有靠瞬移完成上下世界穿越。

这些检查不代表已从出生点手动跑通全部路线。跳跃节奏、翻转后的落点容错、相机舒适度、出生/重生流程、运行性能和打包版本仍需独立试玩验证。
验证输出保存在 `Saved/half_mobius_static_checks.json`、`Saved/pressure_plate_pie_checks.json` 等本地报告中，不作为游戏运行依赖。
