# 墙沿攀爬（Mantle）

## 操作

- 短按空格立即跳跃，不等待长按阈值。
- 按住空格超过 `MantleHoldTime` 后持续尝试攀爬；在地面、起跳和下落时都可以触发。
- 面向近处墙沿，且台面、角色空间和整段路径均有效时，自动抬升、前移并站上台面。
- 一次按住最多触发一次；触发后松开不会中断动作，再次攀爬需要松开后重新按下。
- 攀爬期间暂停普通位移、跳跃和下蹲，但允许自由转动视角；重力镜头翻转期间仍锁定视角。
- 攀爬轨迹在动作开始时确定，转动视角不会改变已经选定的落脚点。
- `AutoBhopFunction` 仍保留；成功触发一次攀爬后，该次按住不再自动起跳。

## 调参位置

`BP_PlayerCharacter` 的类默认值：

| 参数 | 默认值 | 含义 |
| --- | --- | --- |
| `bEnableMantling` | true | 是否启用空格长按攀爬 |
| `MantleHoldTime` | 0.25 秒 | 从空格按下开始计时 |

`CharacterMovement` 组件的 `Movement / Mantle` 分类：

| 参数 | 默认值 | 含义 |
| --- | --- | --- |
| `MantleMaxHeight` | 60 cm | 角色胶囊中心到墙顶，沿重力反方向测量的最大高度差 |
| `MantleWallDistance` | 60 cm | 胶囊半径以外的前方探测距离 |
| `MantleDuration` | 1 秒 | 完整动作耗时 |
| `bDrawMantleDebug` | false | 显示探测线、目标胶囊及拒绝原因日志 |

胶囊尺寸读取运行时值。默认角色胶囊半高为 160 cm，不能把最大攀爬高度理解成离脚底 120 cm。

## 检测与限制

- 使用角色自身碰撞通道和响应，忽略角色自己；墙体需要阻挡角色。
- 要基本正对墙面，不把缓坡当墙。
- 墙沿和落脚点必须来自同一个碰撞组件，且具有可站立法线。
- 检查落脚点前后左右支撑、完整胶囊空间，以及抬升、越沿、落脚三段胶囊路径。
- 胶囊中心低于台面不超过 `MantleMaxHeight`，高于台面不超过 60 cm。
- 下蹲、Root Motion、已有其他特殊移动模式时不启动攀爬。
- 使用自定义移动模式，途中发生阻挡、目标组件失效/移动/关闭碰撞、重力改变或传送时取消并恢复下落。
- 重生和重力镜头翻转会清理角色输入状态；翻转期间不触发攀爬。
- 首版不包含悬挂、攀墙横移、动画、移动平台跟随或多人移动预测。

## 人工验收

保存场景并重启编辑器加载最新 C++ 模块后，在 PIE 中检查：

1. 面向宽平台，短按只跳跃；长按在接近可达墙沿时攀上。
2. 持续按住不会连续攀上第二级，也不会攀上后自动跳走；松开后可再次操作。
3. 太远、太高、斜对墙面、窄台、头顶/前方受阻时不触发。
4. 攀爬中松开空格仍完成一次动作；新出现阻挡时取消，而不是穿透。
5. 攀爬中触发重力反转或重生后，不被原轨迹继续拖动。
6. 正向/反向重力均检查可达墙沿及完成后的站立。
7. 分别开启和关闭 `AutoBhopFunction`，检查跳跃、连跳和攀爬。
8. 在低帧率与高帧率下检查转折点不会斜切墙沿。
9. 攀爬中左右、上下移动鼠标，视角应正常转动，角色仍沿原轨迹完成攀爬；重力镜头翻转期间仍不能转动视角。
